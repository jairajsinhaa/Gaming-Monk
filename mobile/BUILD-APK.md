# Gaming Monk Android APK

The GitHub Actions workflow at `.github/workflows/android-apk.yml` builds a debug APK on pushes to this branch when files under `mobile/` change.

After the workflow finishes:
1. Open the repository's Actions tab.
2. Open **Build Gaming Monk Android APK**.
3. Download the **gaming-monk-android-apk** artifact.

This is a debug APK for testing, not a Play Store release build.
